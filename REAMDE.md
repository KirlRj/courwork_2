## Описание:

Проект "Курсовая работа №2 SkyPro" - это выполнение задач на языке Python в рамках курсовой работы курса "Python разработчик"

На текущий момент в проекте есть следующая функциональность:
1) Вывод списка самолетов, находящиеся на территории определенной страны.
2) Вывод информации о самолетах: ICAO24 код, Позывной, Статус положения (На земле, в воздухе), Высота (если на земле, то высота = 0), Страна регистрации.
3) Функционал записи, чтения, хранения, удаления данных файла
4) Функционал, определяющий топ N самолетов по высоте. Функция get_top_n_by_altitude в scr/interface.py
5) Функционал, который выводит список самолетов по фильтрации страны происхождения. Функция filter_by_registration_country в scr/interface.py.
6) Интерактив. main.py

## Тестирование:

Для тестирования использовался фреймворк pytest.
Если у вас его нет, то скопируйте команду для установки.
```
poetry add --group dev pytest
```
Для проверки покрытия тестами, использовалась библиотека pytest-cov.
Если ее нет, то скопируйте команду для установки.
```
poetry add --group dev pytest-cov
```
Для проверки покрытия тестами используйте команду.
```
poetry run pytest --cov
```
Для формирования отчета об покрытии тестами в формате HTML, используйте команду.
```
pytest --cov=src --cov-report=html
```
где src - пакет с модулями, которые тестируются.
Отчет будет находиться в htmlcov/index.html
